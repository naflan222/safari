# Ceylon Safari Tours

Static, responsive website for Ceylon Safari Tours, Tangalle, Sri Lanka.

## Hosting

Vercel project: safari. Root Directory: `Trips`. Framework: Other. No build or install command is required. Production: https://safari-chi-weld.vercel.app/

Pages: Home, Travels, Bike Rental, About Us, Contact. Enquiries open WhatsApp for the visitor to review and send; there is no booking backend or automatic reservation.

## Content

Business details and photos supplied by the owner. Bike illustrations are generic, not product photographs. Rates, inclusions and rental terms are confirmed directly with the business.

Tour route inspiration supplied by the owner, rewritten as suggested routes (all 7 days or less):
- https://www.tourslanka.com/tours/lankan-heritage-in-3-days/
- https://www.tourslanka.com/tours/beach-and-the-wild/
- https://www.tourslanka.com/tours/sri-lanka-6-nights-7-days-itinerary/
- https://www.tourslanka.com/tours/bird-watching-tour/

The 5-day route includes an original suggested day order based on the source highlights. All routes require final operational confirmation with Ceylon Safari Tours. No affiliation with Tourslanka is claimed. No competitor prices, promises, photos or testimonials are used.

Original purchased template documentation and license are retained in their folders.

Tour-card imagery: four AI-generated Sri Lankan travel illustrations (heritage, Galle coast, hill-country tea traditions, rainforest wildlife). These are illustrative composites, not documentary photographs. Prompts recorded in Documentation/tour-artwork-prompts.md.
